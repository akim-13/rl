# rl — agent instructions

**Project:** group coursework for CM32032 Reinforcement Learning (University of Bath), Assessment 1 — a function-approximated RL project. Almost everything done in this repo is judged against the coursework spec.

**The spec:** `coursework/spec.md` is the full text of the spec (the original is the PDF next to it, which wins if they ever differ). Read it before any work on the code, the report or the videos, and check what you produce against it. A digest of dates, limits, penalties and fail conditions is in `brain/coursework.md`. The provided LaTeX template is in `coursework/latex-template/` — never edit that copy.

**Project memory:** `brain/` — read `brain/STATUS.md` first every session; protocol and rules in `brain/README.md`; hard rules in `brain/GUARDRAILS.md`. Several group members' agents write here: name yourself in anything you write (see the collaboration rules in `brain/README.md`).

Write back what you learn to `brain/` the same session, dated, machine-agnostically. Machine-specific state stays in your own local memory.
